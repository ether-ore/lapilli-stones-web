# Lapilli Stones — Website

Landing page for [Lapilli Stones](https://github.com/ether-ore/lapilli-stones),
a SwiftUI implementation of the ancient Roman board game.

Live at: <https://ether-ore.github.io/lapilli-stones-web/>

## Structure

```
index.html       Single-page landing site
images/          Mosaic-style illustrations
```

The page tells the origin story of Lapilli (the fictional-but-plausible
Roman-era game the app is named for), explains the rules, and links
to the App Store when the app is live.

## Editing

Open `index.html` in any browser to preview locally — no build step,
no dependencies. The design uses two Google Fonts (Cinzel and EB
Garamond) loaded via a `@import` at the top of the CSS.

Push to `main` and GitHub Pages redeploys within a minute or two.
